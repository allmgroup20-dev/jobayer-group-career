## 📜 Usage Contract

1. Every audit run **must** consult Parts 01–02 before starting and Part 13 for governance.
2. Every finding **must** carry an evidence class (Part 04 §4.3).
3. Every repository item **must** be classified in the Coverage Matrix (Part 04 §4.6).
4. No final certification is issued without the governance gate (Part 13 §13.2).
5. On conflict, the canonical AIOS (this layer) takes precedence over implementation.
6. Framework changes only via the amendment process (Part 13 §13.4); the traceability matrix is refreshed on every change.
