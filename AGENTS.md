- User understands **only Bengali**. Ask questions and explain **only in simple, full Bengali** (সহজ সরল ভাষায়, একজন সাধারণ মানুষও যেন বুঝতে পারে), with examples if needed. Never ask questions in English or other languages.
- Store important preferences here so mistakes are not repeated.

## Project overview

- **Root app** (`CFWEB/`): Next.js on Cloudflare Workers via OpenNext. Deployed as `jobayer-group-career` Worker (`https://career.jobayergroup.com`). Shared D1 `jgcareer-db` (id `3e54502f-3cc2-4529-a082-3019726a7784`) + KV `CACHE` (id `6ee0dd4bc9b147feb8400759e6ce33be`).
- **join-app** (`join-app/`): Next.js on Cloudflare Workers via OpenNext. Deployed as `youtube` Worker (`https://youtube.earner.workers.dev`). Same shared D1 + KV.
- **chat-worker** and **ai-app**: supporting workers.
- Deploy only via CI (GitHub Actions on push to main): root = `deploy.yml` (paths `src/**`), join-app = `deploy-join.yml` (paths `join-app/**`). No wrangler auth available in this environment.
- `cloudflare_execute` tool is **read-only** (D1 query via `POST /accounts/{account_id}/d1/database/{db_id}/query`).

## Critical rules (learned the hard way)

- **Any new DB column MUST be added to the fast-check `SCHEMA_COLS` list (root `src/lib/db/index.ts`) or the worker's `ensureWorkerProfileColumns()` (join-app `src/lib/queries.ts`)** — otherwise the schema block is skipped and columns never get created (caused the login redirect loop, fixed in `aab7b06`/`0b7e7a4`/`ac4df08`).
- DB column for union is `union_name` (`UNION` is a reserved SQLite keyword — plain `union` fails at ALTER).
- New location columns live in 4 places: join-app `ensureWorkerProfileColumns()`, join-app API routes, root `src/lib/db/index.ts` (SCHEMA_COLS + forced migration), root API routes + dashboard.
- Keep `city` column populated (aliased to upazila / city corporation / pourashava) so `profileCompleted` logic keeps working.
- Geo data is served as **static assets** (free + unlimited on Cloudflare, served from CDN edge) — NOT via API endpoints, to support very large user counts on the free plan.

## Data sources (verified)

- Divisions/districts/upazilas/unions/pourashavas: iqbalhasandev/bangladesh-geo-json (MIT) — `https://iqbalhasandev.github.io/bangladesh-geo-json/bangladesh-geo.json`
- Dhaka North (54 wards) / Dhaka South (57 wards) ward→area: raadu/dhaka-city-corporation-data — `https://raw.githubusercontent.com/raadu/dhaka-city-corporation-data/master/city_corp.json`
- Non-Dhaka city corporations: ward counts from official portals/Wikipedia; only verified ward→area names are included, otherwise "Ward N" + free-text area.
- Pourashava wards: 1–9 (user choice); keep ward list data-driven so it can be corrected later.
- Only add **verified** data; never fabricate location data.
